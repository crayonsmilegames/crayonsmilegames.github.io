## 연출의 의미

수학 정답, 장바구니, 구매 배지 예시를 넣지 않는다. 앱은 가로 화면이므로
세로 영상에서도 가로 태블릿 화면을 보존한다. 실제 앱 스크린샷을 고르는
세 번의 시연 클릭을 연출한다. 이것은 입력을 녹화한 플레이 영상이 아니라
**실제 앱 화면으로 구성한 소개 연출**임을 페이지에 밝힌다.
학습 효과, 교사 인증, 평점, 다운로드 수, 무료 콘텐츠 범위를 지어내지 않는다.

| 기준 시간 | 메시지 | 주요 연출 |
|---|---|---|
| 0–4초 | 소미 키즈월드 · 놀이가 배움이 되는 시간 | 한글 입자 제목, 부제 차례 등장 |
| 4–16초 | 한글·색칠·이야기를 직접 골라요 | 가로 태블릿, 3회 선택, 커서·물결, 공유 요소 확대 |
| 16–24초 | 골라요 → 해봐요 → 또 놀아요 | 3단계 흐름도, 선·점·상자 순차 등장 |
| 24–30초 | CrayonSmile · 지금 만나보세요 | 두께 있는 타이포·로고 착지, 색칠놀이 함께 소개 |

실제 전환 시각은 기존 게임 BGM의 분석된 박 중 기준 시간에 가장 가까운
시각을 사용한다. 마지막 27–30초는 모든 시각 요소를 정지해 읽는 시간을 준다.

## 구현과 단계별 확인

TypeScript + HTML/CSS + SVG + Canvas 2D. 브라우저 런타임 라이브러리 없음.
1. 먼저 입자 제목을 구현해 화면에서 확인한다. 마스크 알파가 128보다 큰 점을
   샘플링한다. 면적과 입자 수로 간격을 정하고 Float32Array에 저장한다.
   마스크는 글꼴 준비와 화면 형식 변경 때만 다시 계산한다.
2. 부제를 글자 단위로 배치하고 지연·오버슈트·착지 눌림을 준다.
3. 가로 태블릿 틀, 작은 원근 기울기, 그림자·반사 띠를 추가한다.
4. 3회 클릭을 대본 배열로 작성하고 곡선 이동·멈춤·파문을 시간에서 계산한다.
5. 선택 이미지의 작은 배치와 큰 배치를 실제로 적용·측정해 FLIP 역변환을
   캐시한다. 시간에 따라 역변환을 풀고, 끄면 바로 전환한다.
6. 흐름도 경로 길이를 측정하고 대시 오프셋으로 그린다.
7. BGM을 미리 분석해 32개 로그 주파수 띠·저음·박 시각을 저장한다.
   웹과 렌더 모두 이 표를 사용한다. 실시간 분석기의 프레임마다 달라지는 값을
   영상 시계로 쓰지 않는다. 소리는 사용자가 재생을 선택한 뒤 켤 수 있다.
8. CSS 다층 글자로 입체 두께를 만들고 회전·착지·빛을 추가한다.
9. 모든 장면은 renderAt(t)로 계산한다. 같은 시각·형식·옵션이면 같은 화면.
   재생/일시정지/되감기/탐색·속도 조절을 제공한다. 비교 조절판은 studio 모드에
   두고 일반 방문자의 소개 페이지와 구분한다.
10. 같은 코드를 1/30초마다 헤드리스 브라우저로 캡처한다. 가로 1920×1080,
    세로 1080×1920, 각각 900프레임과 음악·효과음으로 정확히 30초 MP4를 만든다.

기존 프로젝트 BGM과 짧은 효과음을 재사용한다. 이번 버전은 자막·음악·효과음
구성이며 새 음성 내레이션을 생성하지 않는다. 이미지·음성 임시 대체물은
최종 배포하지 않는다. 아이에게 구매를 권하는 문구를 넣지 않는다.

- 가로·세로 각 주요 시각 및 마지막 3초 정지, 임의 순서 탐색의 동일성 확인.
